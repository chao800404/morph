# 距離產品目標：一頁摘要（2026-10-15）

依據：`origin/main` `afb7d36` 上的 [`ROADMAP.md`](../ROADMAP.md) 與 GitHub 上的 PR 狀態。這是位置判斷，不是日期承諾；未驗收的項目不寫成完成。

## 目標（ROADMAP 1.1～1.3）

作者用框架原本的寫法撰寫 Theme，Design 逐步接上這些寫法，而不是要求作者改寫；所有框架用同一套內容 API。框架接入順序：TanStack Start 原生 → Astro → React Router（目標版本待 #231 審閱）→ 通用 Vite 託管 → Next.js。託管、預覽、發布在 Cloudflare 上運作。

## 一句話位置

地基大致完成；第一個框架（Start）的內容綁定接近完成本機驗收；第二個框架（Astro）只有託管（L1），還沒有 Design；雲端驗收與共用讀取核心是接下來的兩道關卡；其後三個框架尚未開始。

## 已完成（已合併且有驗證；皆為本機或 GitHub CI，Cloudflare 部署環境未驗）

- CMS／商務核心、Theme 工作區（多檔 OCC、版本歷史與還原）、`public/` 靜態檔與媒體庫、SVG 隔離。
- 建置與部署安全：部署前檢查未套用的 migration、wrangler 加固、Theme Worker 無公開入口。
- TanStack Start：相容步驟 1～3；完整 Start 預覽本機驗收（仍為 opt-in）；內容綁定的 Start 案例主要部分（#211、#212、#216、#217、#224）。
- Astro L1：建置、預覽、發布、回滾與草稿內容同步（A1～A6c），仍在 `MORPH_ASTRO_THEMES=1` 開關後。
- 編輯器可靠性：近期 #227、#229 已合併；#234、#235 為草稿（畫布輸入時的換框、Inspector 修改與媒體簽章的競態）。這類工作降低資料遺失與畫面不一致的風險，但不推進路線圖的框架順序。
